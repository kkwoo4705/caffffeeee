# 프렙 카페 운영 기록 프로그램 PRD 초안

## 사용 목적

카페 운영자가 판매·비용·재고 기록을 관리하고, 메뉴별 수익성과 기간별 실제·예상 손익, 재료 잔량과 발주 참고 정보를 확인하는 웹 프로그램을 만든다.

**수업 중 MVP**(첫 구현에 포함할 핵심 기능)는 판매 입력에서 시작해 메뉴 수익성, 손익, 재고 잔량 확인까지 이어지는 요청 기능 전체다. 첨부된 가상 매장 자료는 시연·검증용으로만 사용하며, 실제 매장 기록과 섞이지 않게 한다.

## 자료의 종류·기간·단위·중복 주의사항

### 확인된 자료

출처는 직접 구성한 가상 매장 ‘프렙 카페’다. 엑셀과 JSON은 같은 기록이며, 엑셀은 데이터 안내 탭을 포함해 13개 탭이다(아래 기록 탭 12개와 안내 탭).

| 자료 | 기록 수 | 내용 |
|---|---:|---|
| 공급사 | 3 | 공급사 ID와 이름 |
| 재료 | 11 | 기준 단위, 구매 용량·가격, 납기·안전재고 일수 |
| 메뉴 | 8 | 메뉴명, 판매 기준가, 분류, 레시피 버전 |
| 레시피 | 22 | 메뉴 한 개에 필요한 재료량과 적용 채널 |
| 재료가격이력 | 33 | 재료별 구매 가격과 적용 시작일 |
| 영업달력 | 457 | 영업·마감 여부, 날씨, 메모 |
| 판매기록 | 6,112 | 일자·메뉴·채널별 판매량 및 당시 금액·원가·수수료 |
| 초기재고 | 11 | 첫 영업 시작 전 재료 수량 |
| 재고기록 | 1,515 | 입고·폐기·실사 조정 |
| 월비용계획 | 120 | 월별 비용 계획 |
| 비용기록 | 3,560 | 날짜별 비용 |
| 자료정보 | 10 | 매장명, 기간, 통화 등 |

주요 기록 기간은 **2025-07-01~2026-09-18**이며, 영업달력은 2026-09-30까지 있다. 금액은 원화·부가세 제외이고, 재료 단위는 g·ml·개다.

### 기획 시 주의사항

- 엑셀과 JSON은 같은 자료이므로 둘 다 가져오면 중복된다. 한 형식만 가져온다.
- 판매기록은 주문별 내역이 아니라 **날짜·메뉴·판매채널별 하루 합계**다.
- 월비용계획과 비용기록은 같은 비용을 월 단위와 일 단위로 나눈 기록이다. 서로 더하면 비용이 중복된다.
- 구매 가격은 포장 단위 전체의 금액이며, 레시피 사용량은 메뉴 한 개에 필요한 양이다.
- 판매 당시 가격·할인·순매출·수수료·개당 원가 기록은 과거 기록이다. 앞으로 적용할 계산 기준을 정한 것은 아니다.
- 재고 증감에서 입고는 양수, 폐기는 음수다. 실사 수량은 실제로 센 수량이다.
- 빈칸은 0과 다르며, 아직 마감하지 않은 날짜의 판매를 0으로 간주하지 않는다. 연간 조회에는 일부 기간만 담길 수 있다.

## 사용자와 사용 순서

주 사용자는 **카페 운영자 또는 매장 기록 담당자**로 본다. 세부 사용자 계정과 권한은 정하지 않았다.

1. 실제 매장 기록을 직접 입력하거나 제공된 엑셀 양식으로 가져온다.
2. 판매와 비용 기록을 입력·수정·삭제한다.
3. 재료 입고·폐기·실사 수량을 기록한다.
4. 메뉴별 수익성과 선택한 기간의 실제·예상 손익을 확인한다.
5. 재료 잔량과 발주 참고 정보를 확인한다.
6. 저장 자료 전체를 백업하고 필요할 때 복원한다.

## 필수 기능

### 수업 중 구현할 핵심 기능(MVP)

- 판매 기록을 날짜·메뉴·판매채널별 하루 합계 단위로 입력·수정·삭제한다.
- 비용 기록을 입력·수정·삭제한다.
- 판매·비용·입고·폐기·실사 기록을 위한 엑셀 양식을 내려받고 가져온다. 메뉴·재료·레시피·공급사 같은 기준정보는 엑셀 가져오기 범위에서 제외한다.
- 메뉴 수익성은 **메뉴에 직접 연결된 비용**을 기준으로 확인한다. 직접 비용에는 재료·포장·결제 수수료가 해당한다. 월세와 같은 공통비는 메뉴별로 배분하지 않고 전체 기간 손익에서 확인한다.
- 실제 손익과 예상 손익을 일·주·월·분기·반기·연간 기간으로 조회한다. 예상 손익은 선택한 조회 기간이 끝나는 시점까지 확인한다.
- 재료 입고·폐기·실사 수량을 기록하고 재료 잔량과 발주 참고 정보를 제공한다. 발주 참고에서는 가장 최근의 실사 수량을 우선한다.
- 기록을 저장하고, 프로그램에 저장된 거래·재고 기록과 기준정보 전체를 백업·복원한다.
- 빠진 정보나 잘못된 입력을 기본적으로 확인하고 사용자에게 알린다.

### 수업 후 확장 후보

아래 기능은 MVP에 포함하지 않으며, 후속 작업 때 필요성을 다시 확인한다.

- 여러 매장 관리와 사용자별 권한
- POS(판매 시점 관리 시스템) 자동 연동
- 공급사에 발주를 자동 전달하는 기능
- 더 다양한 예측 분석

## 제외 기능

- 위 수업 후 확장 후보는 이번 MVP에서 제외한다.
- 계산식, 화면 디자인, 기술, 입력의 세부 동작, 코드와 같은 구현 상세는 이 PRD에서 정하지 않는다.

## 완료 기준

- 판매·비용 기록을 추가·수정·삭제한 결과가 저장되고 관련 조회에 일관되게 반영된다.
- 엑셀 양식으로 판매·비용·입고·폐기·실사 기록을 가져올 수 있고, 잘못된 입력을 식별할 수 있다.
- 메뉴 수익성, 실제·예상 손익, 재고 잔량과 발주 참고 정보가 합의한 기준 사례와 대조해 정확하게 표시된다.
- 일·주·월·분기·반기·연간 조회가 동작하며, 자료가 일부 기간만 있는 경우 그 범위를 오해하지 않게 확인할 수 있다.
- 저장 자료 전체를 백업한 뒤 복원했을 때 기록과 기준정보가 보존된다.
- 누락·잘못된 입력과 같은 기본 오류 상황에서 데이터가 조용히 잘못 반영되지 않으며, 사용자가 문제를 알아볼 수 있다.
- 수업에서 기획·화면 설계·개발·검사·배포를 거친 뒤, 핵심 흐름인 **판매 입력 → 메뉴 수익성 확인 → 손익과 재료 잔량 확인**을 사용할 수 있다.

## 미정 사항

아래 항목은 자료만으로 정할 수 없으며, 이 PRD에서 임의로 확정하지 않는다.

- 메뉴 수익성, 실제·예상 손익, 재료 잔량과 발주 참고 정보의 구체적인 계산 기준
- 예상 손익을 산출할 때 사용할 자료와 예측 방법
- 실사 후 입고·폐기 기록을 반영하는 방식과 발주 참고량 산정 기준
- 주·분기·반기·연간 기간의 시작일 기준 및 일부 기간을 표시하는 방식
- 엑셀의 세부 항목, 가져오기 중복 확인과 오류 처리 방법
- 저장·백업·복원의 구체적인 형식과 위치
- 세부 화면 구성, 기술, 계정과 권한
