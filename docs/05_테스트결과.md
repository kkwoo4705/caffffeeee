## 구현 범위와 운영 환경 차이

`design` 폴더의 `_1`, `_3`, `_5` 시안을 화면 배치·색상·기록 입력 참조로 사용했다. 문서에 확정된 기능 범위와 검산값을 우선 적용했으며, 시안의 가상 매출·원가·예측 숫자와 시안에만 있는 기능은 이 EPIC에 추가하지 않았다. 샘플 자료에서 메뉴·재료 선택 목록만 읽었고, 샘플 거래 기록은 저장소에 넣지 않았다.

현재 작업 환경에는 Next.js·Node.js와 Supabase 설정이 없어 사용자가 바로 눌러 볼 수 있도록 Python 표준 라이브러리 서버와 SQLite를 로컬 검사 경로로 만들었다. 기록은 브라우저 저장소가 아니라 작업 폴더의 `runtime/prep-cafe.sqlite3`에 저장되고, 서버 로그인 세션과 비밀번호 해시를 사용한다. **이 실행 경로는 TRD의 Next.js·Supabase 운영 구성을 대체하거나 클라우드 배포를 검증한 것이 아니다.** 실제 운영 배포와 Supabase 연결은 이 내부 확인에서 검증하지 않았다.

# EPIC 2 테스트 결과

## 상태

- **대상:** EPIC 2. 메뉴 수익성·손익·재료 잔량을 확인하기
- **현재 상태:** 구현과 격리 데이터베이스의 계산 검사를 마쳤다. 브라우저의 사용자 확인은 대기 중이며, 개발 계획에서 EPIC 2를 완료로 표시하지 않았다.
- **확인 주소:** [로컬 테스트 앱](http://127.0.0.1:8765/)
- **실행 명령:** 작업 폴더에서 `python3 app.py` 실행. 기본 주소는 `http://127.0.0.1:8765/`이다.
- **브라우저 상태:** 최신 코드로 서버를 다시 시작했고 첫 운영자 계정 설정 화면을 열어 두었다. 계정·비밀번호 입력은 사용자가 직접 한다.

## 내부 검사

| 확인 항목 | 결과 | 근거 |
|---|---|---|
| Python 문법 및 카탈로그 JSON | 통과 | `PYTHONPYCACHEPREFIX=/private/tmp/prep-pycache python3 -m py_compile app.py`; `python3 -m json.tool web/catalog.json` |
| 날짜 기준 원가 스냅샷 | 통과 | 2026-09-18 카페라떼 포장 판매 기준 재료비 1,123.2원, 포장비 166.4원. 샘플 가격이력의 적용일 단가와 채널 전용 포장 레시피 사용 |
| 메뉴 직접 수익성 집계 | 통과 | 격리 DB에서 600원 순매출, 직접비 250원일 때 공헌이익 350원, 이익률 58.3% 확인 |
| 월 실제 손익 집계 | 통과 | 격리 DB에서 순매출 600원 − 직접비 250원 − 공통비 120원 = 영업이익 230원 확인 |

| 발주 참고량 올림 | 통과 | 하루 사용 200ml, 샘플 기준 납기 1일 + 안전재고 1일에서 목표 400ml, 부족량 250ml, 포장 1,000ml 기준 1포장 확인 |

| 실제 브라우저 첫 화면 | 확인 | 브라우저에서 최신 서버와 운영자 설정 화면이 표시됨. 인증 전이므로 EPIC 2 화면 조작은 사용자의 브라우저 확인 대기 |

계산 검사는 실제 작업 DB와 분리한 임시 SQLite 데이터베이스에서 했다. 샘플 파일에서는 메뉴·재료·레시피·가격이력·포장량·납기·안전재고 기준정보만 읽었고, 판매·비용·재고 거래 행은 가져오지 않았다. 새 판매에는 해당 날짜 기준 재료·포장 원가 스냅샷을 저장해 이후 기준 가격이 바뀌어도 과거 집계가 소급 변경되지 않게 했다. 다만 샘플 기준정보는 가상값이므로 실제 매장 원가로 간주하지 않는다.

## 범위와 제한

- EPIC 2에는 메뉴 직접 수익성, 월별 **실제** 손익, 최근 실사 기준 잔량·발주 참고를 구현했다. 손익 예상, 월 이외 기간, 엑셀, 백업·복원은 다음 범위로 남긴다.
- 기준정보는 첨부된 가상 샘플을 참고한다. 이 로컬 앱에는 메뉴·레시피·재료 원가·포장·납기·안전재고 기준을 관리하는 편집 화면이 아직 없다.
- 하루 평균 사용량은 최근 실사 이후 판매 사용량을 경과한 달력일로 나눠 계산한다. 재고자료의 납기·안전재고 값은 샘플 기준이며, 매장 영업일 달력은 반영하지 않는다.
- 실제 브라우저 계정 입력, 사용자의 버튼 조작, 배포 또는 Supabase 연결은 아직 확인하지 않았다.
